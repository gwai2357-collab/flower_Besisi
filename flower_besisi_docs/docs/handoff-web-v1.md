# 핸드오프: 꽃망울 웹 1단계 (화면 흐름, 저장 없음)

꽃을 꾸며 링크로 보내고, 받은 사람이 3D로 받아 보는 웹. 이번 단계는 **저장·로그인 없이 보내기 → 받기 화면 흐름**을 끝까지 만드는 것.
결정 기록 전체: `docs/bouquet-backlog.md` (특히 "UI 스케치 반영"·"구현 전 확인 답변" 섹션, 2026-11-19).

## 0. 기본 정보
- 저장소: https://github.com/gwai2357-collab/flower_Besisi
- 기술: Vite + 순수 JS + three.js. 프레임워크 없음.
- 기기 기준: 카카오톡 안 브라우저, 휴대폰 세로(기준 390×660).
- 작업 방식: 단계마다 브랜치 + PR. 사용자가 확인 후 합침. Vercel 미리보기 링크로 휴대폰 확인.
- 이번 범위 밖: Supabase 저장, 카카오 로그인·공유 SDK, 보이스 녹음, 썸네일 서버 생성, 소리, 영어판.

## 2. 구조 (편집이 쉽게)
- `src/theme.css`: 색·글꼴·둥글기·간격을 CSS 변수로. **배경색 변수 하나로 3D 배경까지 바뀌게.**
- `src/strings.ko.js`: 화면 문구 전부(나중에 영어판 대비).
- `src/screens/`: 화면 하나당 파일 하나(`send-1-flowers.js`, `receive-2-dome.js` …). 절대 위치 대신 세로로 쌓는 레이아웃.
- `src/scene3d/`: 렌더러·PS1 효과·말풍선·소포·캐릭터. 꽃다발은 `renderBouquet(data)` 하나로만 그리게(나중에 꽃 생성기로 교체).
- `src/state.js`: 화면과 분리된 데이터(나중에 저장·앱 껍데기에서 재사용).
- `/storyboard.html`: 모든 화면을 휴대폰 크기로 나란히 보는 페이지.
- `?dev=1` 조절 패널: 배경색, PS1 해상도, 흔들림, 아무 화면으로 건너뛰기.
- 저장 없이 시험: 선물 데이터(JSON)를 링크 `#` 뒤에 담아 다른 폰에서도 받기가 열리게. 그림 편지는 길이 문제로 같은 기기에서만 보여도 됨.

## 3. 공통 요소
- 바탕 UI는 부드러운 스타일, **레트로(PS1)는 3D에만**. 말투는 다정하게.
- 배경: 단색 + PS1(화면 해상도 300, 꼭짓점 흔들림 꽃다발 550 · 소포 350 · 선물 820). 꽃다발 : 소포 = 2 : 1.
- 상단 바: 왼쪽 로고(웃는 얼굴 + `@` 꽃 문자 로고, 임시) + 뒤로가기, 오른쪽 설정 아이콘 하나(효과음·BGM·VR 기울기 묶음, BGM 기본 꺼짐. 이번엔 자리만).
- 말풍선: 3D 뭉게구름(로우폴리, PS1), **앞면은 평평**. 글씨는 3D가 아니라 위에 얹은 HTML.
- 3D 보기: 드래그 회전, 두 손가락 확대. 화면을 스크롤해도 꽃다발은 고정(아래 패널만 올라옴).

## 4. 보내기
**S0 진입**
- 가운데 3D 꽃다발, 말풍선 "꽃을 꾸미고 링크로 전해요" 같은 소개.
- 좌우 화살표로 미리보기 전환(꽃다발 → 한 송이 → 선물 → 스냅사진), 천천히 자동으로 넘어감.
- "어떻게 마음을 전할까요?" 큰 버튼 두 개: 한 송이(소요 5분) / **꽃다발(강조, 10~15분)**.
- 그 아래 작은 링크 "여럿이 함께 준비하나요?" → S0-1. 서비스 공유 아이콘.

**S0-1 함께 모으기 (화면만)**
- 여러 다발이 모인 장면 + 설명 말풍선. "6일 남음, ○월 ○일 마감" 표시.
- To [받는 사람 이름] + 마감일(최대 7일) 입력.
- 미리보기("지우의 생일 꽃망울") + 확정 → 링크 복사. 팝업 없음.

**S1 꽃 꾸미기**
- 위: 3D 다발, 말풍선 "꽃을 고르고 어울리는 소재를 골라 보세요", 되돌리기 버튼.
- 아래 패널(올리면 커짐):
  - 버튼 줄: 모두 삭제 / 위치 섞기 / 추천 조합.
  - 탭: **꽃1 · 꽃2 · 소재 · 포장** (꽃1 = 메인, 꽃2 = 서브. 화면에 "메인/필링"이라고 쓰지 않음).
  - "오늘의 꽃" 강조 칩(날마다 열리는 3~4종 중 하나).
  - 꽃 칩 목록: 이름 길이에 맞춰 흘러가게 배치, 칩마다 ⓘ(누르면 "○○의 꽃말은 ○○예요" 말풍선).
  - 칩을 누르면 다발에 자동으로 꽂힘. 직접 위치를 옮기는 기능은 없음.
  - 개수 표시 n/30 (**최대 30송이, 소재 포함**).
  - 잠긴 꽃은 흐리게 + "받으면 열려요". 기본 꽃(장미·튤립·안개꽃·유칼립투스)은 항상 열림. 튤립·안개꽃은 버튼만.
- 한 송이 모드: 메인 꽃 1송이 + 소재 2~3줄기, 포장은 크라프트 미니 고정.

**S2 카드 + 선물**
- 편지 카드가 크게, 뒤로 소포가 살짝 보임. 기울기 센서로 은은하게 흔들림(센서가 없으면 생략).
- 편지지 색: 다발의 주된 색으로 자동, 칩 4~5개로 바꿀 수 있음.
- 도구 줄: 글자(T) / 펜(**그림 그리기**) / 색 점(누르면 색이 귀엽게 바뀜) / 마이크(보이스메모 최대 15초, 이번엔 버튼만).
- "To ___" 칸(이름은 선택). 글자 300자. 편지 아래 관계 토글(친구·가족 / 연인).
- "함께 준비한 선물이 있나요? ✓ / ✗" → ✓면 S2-1 영역이 스르르 나타남.

**S2-1 선물 추가**
- 3D 소포(기울기 + 드래그 회전), 말풍선 "꽃다발과 함께 넣어 드릴게요".
- 선물 종류: 꽃 고르기와 같은 칩 방식(템플릿 25종, 미스터리 상자는 이름 14자 직접 입력). 색·크기 선택은 없음.
- 선물코드 입력 + 붙여넣기. 확인 질문(선택).
- 안내 두 줄: "보낸 사람이 넣은 코드예요" / "꽃망울은 카카오 로그인·결제 정보를 묻지 않아요".
- 확정.

**S3 캐릭터**
- 말풍선 "이제 거의 다 왔어요! 당신은 누구인가요?". TIP: 캐릭터가 방금 만든 다발의 미니 버전을 듦.
- **닉네임은 여기서 입력**(브라우저에 기억해 다음에 미리 채움).
- 버튼: 기본 / 랜덤 / 확정. 확정하면 그 캐릭터로 고정, 건너뛰면 랜덤 캐릭터. 이미지로 저장 버튼.
- 아래 옵션 패널은 꽃 고르기와 같은 탭·칩·슬라이더 방식(캐릭터 실험 v0의 옵션).

**S4 보내기**
- 카톡 공유 썸네일 템플릿 미리보기 ◁ ▷:
  - A: 캐릭터가 아래에서 빼꼼, 다발은 일부만
  - B: 캐릭터 얼굴 가까이
  - 서프라이즈를 위해 꽃 전체는 보이지 않게.
- 버튼: 링크 복사 / 공유하기(Web Share API).
- "깜짝 선물로 QR 만들기 (와이파이·상품권처럼 꾸밀 수 있어요!)": 가상의 디자인만, 실제 회사 이름·로고는 쓰지 않음.
- 작은 "개발자에게 의견 보내기" 링크(화면만).

## 5. 받기
- **R0 도착**: 디더링이 풀리며 선명해짐. 캐릭터가 다발을 내밂. "○○이 보낸 꽃다발이 도착했어요! 꽃을 눌러 받아 주세요." 다발을 눌러야 받음.
- **R1 바라보기**
  - 캐릭터는 옆으로 쏙 빠지고 다발(카드 꽂힘) + 옆에 소포. 소포는 처음부터 보임.
  - 멘트: "드래그하거나 확대할 수 있어요! 카드와 선물을 같이 보냈네요. 카드부터 열어 보세요!"
  - **카드를 열기 전 소포를 누르면** "○○의 카드가 함께 도착했어요!" 안내만, 열리지 않음.
- **R1-1 카드**: 편지(그림 포함) + 보이스메모 ▶ 자리.
- **R1-2 소포**
  - 소포 누름 → 크게 → 한 번 더 누름 → 띠가 말리며 뜯기고 선물이 튀어나옴(선물 오브젝트 v11 그대로).
  - "○○이 함께 선물을 보냈어요!" + 확인 질문 + 코드 복사 + 선물함 열기 + 안내 두 줄.
  - 아래 "주고받은 마음 보관하기" 버튼(선물이 없으면 카드를 닫은 뒤 나옴).
- **R2 유리돔**
  - 받침대가 올라오고 돔이 덮임, 남은 날에 따라 김이 서림.
  - 문구: "6일 동안 이 돔 안에 머물러요" 방향으로, 겁주는 말투는 피함.
  - 버튼: "카카오로 시작하고 꽃 보관하기"(이번엔 가짜 동작).
  - ⓘ 회원 혜택: 꽃 보관, 도감 채우기, 포토박스 벽.
- **R3 답례 (가입 없이도 가능)**
  - 한 송이 답례하기: S1 화면·흐름 재사용, 메인 꽃 1개.
  - 감사 스냅 찍기: 내 캐릭터가 없으면 S3 먼저. 감사 스냅 v0 그대로.
  - 보관함 가기.
- **R4 보관함 (화면만)**
  - 받은 다발 진열 + 내 캐릭터(닉네임·캐릭터 바꾸기).
  - 도감: "45종 중 9종 모았어요!", 못 받은 꽃은 흐리게. 꽃을 누르면 그 꽃만 크게(◀ ▶, 꽃말, 닫기).
  - 다발 자세히 보기: 선물·편지·날짜·스냅. 다발을 열면 포즈 장면 없이 바로 바라보기 + "다시 받아 보기" 버튼.
  - 탭: 꽃다발 / 도감 / 포토박스 벽. 작은 "개발자에게 의견 보내기" 링크.
- **함께 모으기로 받을 때**: 여러 캐릭터가 한꺼번에 건넴(이번엔 화면만).

## 6. 진행 순서 (단계마다 PR 1개)
1. 뼈대: 구조·theme·strings·PS1 배경·말풍선·공통 부품·화면 전환·storyboard·dev 패널
2. 보내기 S0~S4
3. 받기 R0~R4
4. 함께 모으기 화면

단계가 끝나면 미리보기 링크와 "스케치와 다르게 한 곳·정하지 못한 곳" 목록을 사용자에게 남기기.
